Orange Scarf Studio

Internal production tool of the YouTube channel “Orange Scarf” · uses YouTube API Services

Orange Scarf Studio helps the team behind the YouTube channel “Orange Scarf” plan, produce and publish its own videos.

What it does

  • Uploads finished videos and Shorts to our own YouTube channel, together with title, description, tags, thumbnail, English captions and playlist.
  • Schedules the publication of these videos.
  • Reads public YouTube data (titles, view counts, thumbnails of public videos) to research topics for our channel.

Who can use it

The tool is not offered to the public. Only the channel owner signs in with Google, and it only acts on that one channel.

YouTube API Services

Orange Scarf Studio uses YouTube API Services (YouTube Data API v3) to upload and schedule videos on our own YouTube channel. By using Orange Scarf Studio you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

Privacy and terms

Read how the tool handles data in our Privacy Policy and the rules for using it in our Terms of Service.
