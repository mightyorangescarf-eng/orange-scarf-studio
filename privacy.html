Privacy Policy for Orange Scarf Studio

Last updated: 23 October 2026

1. Who we are

Orange Scarf Studio (“the app”) is an internal tool operated by the owner of the YouTube channel “Orange Scarf”. It is used only by the channel owner to manage that channel. Contact: mighty.orange.scarf@gmail.com.

2. Which Google user data the app accesses

When the channel owner signs in with Google, the app requests these permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos to the owner’s own channel.
  • https://www.googleapis.com/auth/youtube.force-ssl: to set thumbnails, upload captions, add videos to playlists of the owner’s own channel and read the channel’s name.

The app does not access email, contacts, files, or any data of other Google users.

3. How the data is used

The app uses this access only to upload and publish the owner’s own videos and their metadata (title, description, tags, thumbnail, captions, playlist, publication time) and to show the upload status in the internal dashboard. Data is not used for advertising, not sold, and not shared with third parties.

4. Public YouTube data for research

For topic research the app reads public data of public YouTube videos and channels (for example titles, view counts, subscriber counts, thumbnails) through the YouTube Data API. This contains no personal data of signed-in users. It is stored on our server for analysis and refreshed or deleted when it is no longer needed.

5. Storage and security

The Google access token (refresh token) is stored on our own server in Germany (Hetzner, Falkenstein) in a file that only the system administrator can read. It is transmitted only to Google over encrypted connections. Videos and metadata are stored on the same server.

6. Retention and deletion

The token is kept until access is revoked. Access can be revoked at any time at myaccount.google.com/permissions; the app then can no longer access the channel, and we delete the stored token. Upload records are kept as long as the channel’s production archive exists and can be deleted on request.

7. Google API Services User Data Policy

Orange Scarf Studio’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

9. Your rights

Under the GDPR you have the right to access, rectification, erasure, restriction of processing, data portability and objection, and the right to lodge a complaint with a supervisory authority. Contact us at mighty.orange.scarf@gmail.com.

10. Changes

We will update this page when the app’s handling of data changes.
